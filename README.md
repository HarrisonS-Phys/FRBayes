# FRBayes

`FRBayes` is a Python package for Bayesian parameter estimation and statistical analysis of Fast Radio Burst (FRB) dynamic spectra and pulse profiles using JAX and NumPyro.

---

## Prerequisites

* **Python:** `>= 3.10`
* **JAX & NumPyro:** Automatically installed as dependencies.

---

## Installation

### Option 1: Direct from GitHub (Recommended)

Install the latest version directly into your active Python environment:

```bash
pip install git+[https://github.com/your-username/FRBayes.git](https://github.com/your-username/FRBayes.git)
